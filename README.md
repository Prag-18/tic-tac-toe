# 🎮 Tic Tac Toe with AI Opponent

An interactive Tic Tac Toe web application built using **HTML, CSS, and JavaScript**.  
The game supports both **2-player mode** and **AI mode with multiple difficulty levels**, along with smooth animations and a modern UI.

---

## 🚀 Features

- 👥 **2 Player Mode** – Play with another player on the same device  
- 🤖 **AI Opponent Mode**  
- 🎯 **Difficulty Levels**
  - Easy (Random Moves)
  - Medium (Win / Block Strategy)
  - Hard (Minimax Algorithm – Unbeatable AI)
- ✨ **Animated AI Thinking Effect**
- 🎉 **Confetti Celebration on Win**
- 🎨 **Modern Glassmorphism UI**
- 🔄 **Reset and New Game Controls**
- 📱 **Responsive Design**

---

## 🧠 AI Logic

The Hard difficulty uses the **Minimax Algorithm**, which evaluates all possible game states and chooses the optimal move, making the AI impossible to defeat.

---

## 🛠 Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling, animations, and responsive design
- **JavaScript (ES6)** – Game logic, AI behavior, DOM manipulation
